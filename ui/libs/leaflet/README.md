# Leaflet Library for Drone Detection System

This directory contains the Leaflet mapping library and its plugins for the Drone Detection System UI.

## Version Information

- **Leaflet Core**: v1.9.4
- **Leaflet Draw**: v1.0.4
- **Leaflet MarkerCluster**: v1.5.0
- **Leaflet Heatmap**: v0.2.0
- **Leaflet Control Geocoder**: v2.4.0
- **Leaflet EasyButton**: v2.4.0
- **Leaflet Fullscreen**: v1.0.2

## Installation

### Option 1: CDN (Development)
```html
<!-- Leaflet CSS -->
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
<!-- Leaflet JS -->
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
