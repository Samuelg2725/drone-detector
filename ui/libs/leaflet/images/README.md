# Leaflet Images

This directory contains image assets required by Leaflet:

- `layers.png` / `layers-2x.png` - Layer control icons
- `marker-icon.png` / `marker-icon-2x.png` - Default marker icons
- `marker-shadow.png` - Marker shadow
- `spinner.gif` - Loading spinner

## Source

These images are from the Leaflet distribution package.
Download from: https://unpkg.com/leaflet@1.9.4/dist/images/
